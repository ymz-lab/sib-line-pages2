自動投稿の手順（コマンドラインツール）

X は原稿だけで投稿できます。Instagram は撮影・制作した素材の公開URLを登録してから投稿されます。

cd sns-automation
python -m sns_auto import baseai-approved.json     # 承認済み原稿を取り込む
python -m sns_auto media <原稿ID> https://…/reel.mp4   # Instagram の素材URL
python -m sns_auto publish --yes                 # 予定時刻を過ぎたものを投稿
