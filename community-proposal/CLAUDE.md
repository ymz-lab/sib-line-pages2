## 1. 資料の目的（最重要・常に意識する）

- 相澤さんに共有し、相澤さんが知り合いの経営者へ**そのまま送れる**提案資料にする。
- まだ完全決定ではないため、断定しすぎず「**初期構想**」「**実証パートナー募集**」の温度感で作る。
- 営業感は出してよいが、押し売りではなく「**参加相談につながる**」構成にする。

### 禁止表現（全スライド実装後に必ず文言を見直す）

1. 「確定サービス」であるかのような言い切り
2. 学生との接点だけで採用成果を保証するような表現
3. SNSや広報施策で売上が必ず上がるかのような表現
4. 料金が確定であるかのような表現 → 必ず「**候補**」「**実証後に調整予定**」と明記する

### 表現の言い換え指針

| NG | OK |
| --- | --- |
| 〜が得られます | 〜の機会をつくります／〜につながる接点をつくります |
| 採用できます | 採用広報の接点を広げます |
| 売上が上がります | 発信や接点を継続する体制づくりを支援します |
| 月額◯◯円です | 月額◯◯円（候補・実証後に調整予定） |
| 会員募集中 | 初期実証パートナー募集 |

## 2. トーン・デザイン要件

- 16:9 / **1920×1080**
- 白・ネイビー・グレー基調、アクセントはオレンジ（1スライドあたり1〜2箇所程度）
- BtoB向けの信頼感を保つ。**学生団体っぽく安く見せない**
- 文字少なめ・図解中心・**1スライド1メッセージ**
  - ただし料金プラン比較表など情報量が本質的に多いスライドは、表組み・グリッドで整理し、詰め込みすぎないレイアウトにする
- タイトル **48px以上**、本文 **28px以上**
- ページ番号を右下に `01 / 18` 形式で表示
- 図解は画像素材を使わず、**SVGまたはCSSで自作**する
- **「角丸の四角い枠（カード）」を要素の基本単位にしない。** 量産型テンプレートに見える最大の原因。
  構造は原則、**罫線・余白・図形・色面**で示す。枠を使うのは「意図的に1箇所だけ浮かせたい面」
  （P.13 の中央プラン、P.16 の対象パネル、P.18 の CTA）に限る。
- **均一なカードグリッドの連続を避ける。** 内容に応じて図解の型を変える
  （放射図／循環図／レーダーチャート／タイムライン／チェックリスト／枠なしカラム 等）
- 使ってよい表現: 大きい数字や記号を背景に薄く敷く（`.ghost`）、非対称なレイアウト、
  円形・曲線の図形、要素を重ねた奥行き
- **P.05 比較表**：他社・他サービスを不当に貶めない。「目的と向き不向きの違い」というフラットな整理に留め、
  右列の強調は accent の細いバーと薄い着色まで（塗りつぶしにしない）

## 3. デザイントークン

```
Navy（基調）          #0F2A47   --navy
Navy Light（サブ見出し）#3C5A78   --navy-light
White                 #FFFFFF   --white
Gray Light（背景）     #F4F6F8   --gray-light
Gray Text（補足）      #6B7684   --gray-text
Accent Orange（差し色） #F2894B   --accent
Gold（P.15 のみ少量） #C9A063   --gold
```

質感（単色ベタ塗りに頼らない）

```
--navy-grad        linear-gradient(135deg, #1A3F68, #0F2A47 52%, #101E36)
--navy-grad-soft   linear-gradient(140deg, #17365A, #0F2A47 70%)
--accent-grad      linear-gradient(135deg, #F8AC72, #F2894B 52%, #DC7133)
--sh-sm / --sh-md / --sh-lg   影は低不透明度・大ぼかしの2段重ねで、フラットにも重くもしない
```

- navy 面はベタではなく `--navy-grad` を使う
- accent は差し色。強調要素の一部に `--accent-grad` を使ってよい
- gold は「初期実証パートナー」まわり（P.15／P.16 のラベル）だけに少量

フォント（Google Fonts）

- 見出し: **Noto Sans JP / Bold(700)** / 48px以上
- **明朝体・装飾フォントは使わない。** 見出しも本文も Noto Sans JP のみで統一する
- 本文: **Noto Sans JP** / 28px以上
- 補足・ページ番号: **Noto Sans JP** / 18–20px

### 整合性ルール（矛盾を出さない）

- **P.09**：交流会がない月の共通提供内容は「企業紹介／少人数交流／学生イベント参加枠」までに限定する。
  学生リサーチ・個別マッチングは**プランB以上の特典**なので、共通提供内容として書かない。
  ※学生イベント参加枠はP.13でプランB特典に該当するため、P.09では「プランに応じて提供」の注記を必ず添える。
- **P.12 と P.16 の役割分担**
  - P.12 = 関係を通じて継続的に**お願いしたいこと全般**
  - P.16 = **募集の骨子**（対象・募集内容）のみ。手続き的な話はP.16、期待の詳細はP.12。
- **P.15（初期実証パートナーだからこそ、得られること）**
  - 「早期参加者だけの割引」「優先的な特典」など、確定していない条件を断定的に約束しない。
  - あくまで「実証段階という状況そのものが持つ性質」として書く。焦らせる表現（今しかない／枠が埋まる）は使わない。
- **P.13 の箇条書きスタイル**
  - 「◯◯の内容すべて」（他プランからの引き継ぎ項目）のみ、3プラン共通で太字＋濃いネイビーの丸で軽く強調する。
  - それ以外の項目は3プランとも同じ通常表示。プラン個別の丸の色分けはしない。
- **P.13 と P.14 の整合**
  - P.14 グループ1（全プラン共通）＝ 交流／簡易相談／企業紹介／合同交流会参加権 → プランAの内容と一致
  - P.14 グループ2（プランにより追加）＝ 学生リサーチ／採用・広報相談／個別マッチング／学生イベント参加枠の拡大／ミニプロジェクト応募権 → プランB以上（P.13 プランB の追加項目と1対1で対応させること）
  - グループ2はグループ1より視覚的に控えめにし、「全員が同じものを得られるわけではない」ことが一目でわかるようにする
- 料金が「候補」であることは **P.13だけでなく資料全体**（P.09注記・P.14・P.16など）で読み取れるようにする
