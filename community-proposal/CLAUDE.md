## 1. 資料の目的（最重要・常に意識する）

- 相澤さんに共有し、相澤さんが知り合いの経営者へ**そのまま送れる**提案資料にする。
- まだ完全決定ではないため、断定しすぎず「**初期構想**」「**実証パートナー募集**」の温度感で作る。
- 営業感は出してよいが、押し売りではなく「**参加相談につながる**」構成にする。

### 禁止表現（全スライド実装後に必ず文言を見直す）

1. 「確定サービス」であるかのような言い切り
2. 学生との接点だけで採用成果を保証するような表現
3. SNSや広報施策で売上が必ず上がるかのような表現
4. 料金が確定であるかのような表現 → 必ず「**候補**」「**実証後に調整予定**」と明記する

### 表現の言い換え指針

| NG | OK |
| --- | --- |
| 〜が得られます | 〜の機会をつくります／〜につながる接点をつくります |
| 採用できます | 採用広報の接点を広げます |
| 売上が上がります | 発信や接点を継続する体制づくりを支援します |
| 月額◯◯円です | 月額◯◯円（候補・実証後に調整予定） |
| 会員募集中 | 初期実証パートナー募集 |

## 2. トーン・デザイン要件

- 16:9 / **1920×1080**
- 白・ネイビー・グレー基調、アクセントはオレンジ（1スライドあたり1〜2箇所程度）
- BtoB向けの信頼感を保つ。**学生団体っぽく安く見せない**
- 文字少なめ・図解中心・**1スライド1メッセージ**
  - ただし料金プラン比較表など情報量が本質的に多いスライドは、表組み・グリッドで整理し、詰め込みすぎないレイアウトにする
- タイトル **48px以上**、本文 **28px以上**
- ページ番号を右下に `01 / 18` 形式で表示
- 図解は画像素材を使わず、**SVGまたはCSSで自作**する
- **「角丸の四角い枠（カード）」を要素の基本単位にしない。** 量産型テンプレートに見える最大の原因。
  構造は原則、**罫線・余白・図形・色面**で示す。枠を使うのは「意図的に1箇所だけ浮かせたい面」
  （P.13 の中央プラン、P.16 の対象パネル、P.18 の CTA）に限る。
- **均一なカードグリッドの連続を避ける。** 内容に応じて図解の型を変える
  （放射図／循環図／レーダーチャート／タイムライン／チェックリスト／枠なしカラム 等）
- 使ってよい表現: 大きい数字や記号を背景に薄く敷く（`.ghost`）、非対称なレイアウト、
  円形・曲線の図形、要素を重ねた奥行き
- **P.05 比較表**：他社・他サービスを不当に貶めない。「目的と向き不向きの違い」というフラットな整理に留め、
  右列の強調は accent の細いバーと薄い着色まで（塗りつぶしにしない）

## 3. デザイントークン

```
Navy（基調）          #0F2A47   --navy
Navy Light（サブ見出し）#3C5A78   --navy-light
White                 #FFFFFF   --white
Gray Light（背景）     #F4F6F8   --gray-light
Gray Text（補足）      #6B7684   --gray-text
Accent Orange（差し色） #F2894B   --accent
Gold（P.15 のみ少量） #C9A063   --gold
```

質感（単色ベタ塗りに頼らない）

```
--navy-grad        linear-gradient(135deg, #1A3F68, #0F2A47 52%, #101E36)
--navy-grad-soft   linear-gradient(140deg, #17365A, #0F2A47 70%)
--accent-grad      linear-gradient(135deg, #F8AC72, #F2894B 52%, #DC7133)
--sh-sm / --sh-md / --sh-lg   影は低不透明度・大ぼかしの2段重ねで、フラットにも重くもしない
```

- navy 面はベタではなく `--navy-grad` を使う
- accent は差し色。強調要素の一部に `--accent-grad` を使ってよい
- gold は「初期実証パートナー」まわり（P.15／P.16 のラベル）だけに少量

### メッシュグラデーション（全18ページに適用）

- `.mesh--navy`（navy スライド：P.01 表紙／P.15／P.18 クロージング）: navy をベースに、
  明るい青・紺紫・accent orange を radial-gradient で滲ませる。
  文字側は `::after` の暗いレイヤーでわずかに沈ませ、可読性を確保する。
- `.mesh--light`（P.03 VISION／P.04 CONCEPT）: 白〜淡グレーに、淡い青・藤・オレンジをはっきりめに。
- `.mesh--soft` / `.mesh--soft.mesh--tint`（情報量の多いページ）: 同じ色相をごく低コントラストで。
  **文字の可読性を最優先**し、コントラストを上げすぎない。

### CTA

- CTA は**必ずピル型**（`border-radius: 999px`）＋ orange のグラデーション。
  文字色は濃い茶寄りのダーク（`#24170D`）でコントラストを確保する。

### イラストのプレースホルダー（`.illus`）

- 後から画像に差し替える前提の**仮の枠**。薄いグレーの破線＋画像アイコン＋
  「イラスト案: 〇〇のイメージ」の薄い説明文で、明らかに仮だと分かる見た目にする。
- 配置箇所（5箇所）: P.01 表紙（右）／P.03 目指す姿（本文下）／P.08 活動内容（上部）／
  P.16 募集について（下部）／P.18 クロージング（CTA下）。
- navy 背景では `.illus--onnavy` を併用する。差し替えてもレイアウトが崩れないサイズ・余白で置くこと。

### PDF 出力で壊れる CSS（使用禁止）

Chromium の PDF 出力は一部の CSS を再現できず、**画面では正常なのに PDF だけ壊れる**。
書き出し後は必ず PDF をラスタライズして目視確認すること（`pymupdf` で可）。

| 禁止 | 症状 | 代替 |
| --- | --- | --- |
| `background-clip: text`（グラデ文字） | 文字が塗り潰しの矩形になり読めない | 単色 `color` で着色する |
| 大きな `box-shadow`（大ぼかし＋負スプレッド） | ぼけずに灰色の矩形として焼き込まれる | `inset 0 1px 0 rgba(255,255,255,.14)` 等の内側ハイライト |
| `filter: blur()` での背景ぼかし | ラスタライズされ粗くなる／位置ずれ | radial-gradient の柔らかいストップで表現する |

小さめの `box-shadow`（ぼかし30px以下・スプレッド浅め）は CTA 程度なら問題なく出力される。

フォント（Google Fonts）

- 見出し: **Noto Sans JP / Bold(700)** / 48px以上
- 主役スライド（表紙・VISION・CONCEPT・クロージング）のキャッチコピーのみ **Black(900)** を使い、
  補足ラベル・サブテキストは 400〜500 に落として**強弱を大胆につける**
- **明朝体・装飾フォントは使わない。** 見出しも本文も Noto Sans JP のみで統一する
- 本文: **Noto Sans JP** / 28px以上
- 補足・ページ番号: **Noto Sans JP** / 18–20px

### 整合性ルール（矛盾を出さない）

- **プランは1つだけ。** プランA/B/C のような複数プラン、「向いている企業」の書き分け、
  プランごとの特典差分は**一切書かない**。提供内容は P.13 の1リストに統一し、
  「プランにより異なります」「プランB以上」といった差分前提の注記も置かない。
- **P.12 と P.16 の役割分担**
  - P.12 = 関係を通じて継続的に**お願いしたいこと全般**
  - P.16 = **募集の骨子**（対象・募集内容）のみ。手続き的な話はP.16、期待の詳細はP.12。
- **P.15（初期実証パートナーだからこそ、得られること）**
  - 「早期参加者だけの割引」「優先的な特典」など、確定していない条件を断定的に約束しない。
  - あくまで「実証段階という状況そのものが持つ性質」として書く。焦らせる表現（今しかない／枠が埋まる）は使わない。
- **P.13（料金候補）**
  - 提供内容は1リスト。月額は 15,000／20,000／25,000 円の3候補を**優劣なしでフラットに**並べる。
    特定の価格を推す見た目（おすすめバッジ・中央だけ強調 等）にしない。
  - 「どの価格帯が適切だと思われますか」と**意見を求める一文**を必ず添える。
- **P.13 と P.14 の整合**
  - P.14 グループ1（会費内）＝ P.13 の提供内容リストと**完全に同一**にする。
  - P.14 グループ2（別料金）＝ SNS運用支援／動画・LP制作／採用広報制作／本格的な学生プロジェクト／
    イベント企画運営／AI活用支援。金額は書かない。
- 料金が「候補」であることは **P.13だけでなく資料全体**（P.09注記・P.14・P.16など）で読み取れるようにする

## 6. 作業ルール

- フェーズごとに進め、各フェーズの終わりに**必ずブラウザ／生成物で見た目を確認**してから次へ進む。
- 特に P.07（SVGフロー図の矢印とノードの重なり・座標ズレ）、P.13・P.14（情報量が多い）は重点確認。
- **PNG だけでなく PDF もラスタライズして確認する。** PNG は正常なのに PDF だけ壊れる CSS があるため。

```bash
python3 - <<'EOF'
import pymupdf
d = pymupdf.open('output/経営者コミュニティ事業提案資料.pdf')
d[12].get_pixmap(dpi=110).save('/tmp/p13.png')   # 画として確認
print('20,000' in d[12].get_text())               # テキストとして残っているか確認
EOF
```
