# 経営者コミュニティ事業 提案資料 — 制作ガイド

このファイルは本プロジェクト（`community-proposal/`）の唯一の基準ドキュメント。
全フェーズの作業前に必ず参照すること。

---

## 1. 資料の目的（最重要・常に意識する）

- 相澤さんに共有し、相澤さんが知り合いの経営者へ**そのまま送れる**提案資料にする。
- まだ完全決定ではないため、断定しすぎず「**初期構想**」「**実証パートナー募集**」の温度感で作る。
- 営業感は出してよいが、押し売りではなく「**参加相談につながる**」構成にする。

### 禁止表現（全スライド実装後に必ず文言を見直す）

1. 「確定サービス」であるかのような言い切り
2. 学生との接点だけで採用成果を保証するような表現
3. SNSや広報施策で売上が必ず上がるかのような表現
4. 料金が確定であるかのような表現 → 必ず「**候補**」「**実証後に調整予定**」と明記する

### 表現の言い換え指針

| NG | OK |
| --- | --- |
| 〜が得られます | 〜の機会をつくります／〜につながる接点をつくります |
| 採用できます | 採用広報の接点を広げます |
| 売上が上がります | 発信や接点を継続する体制づくりを支援します |
| 月額◯◯円です | 月額◯◯円（候補・実証後に調整予定） |
| 会員募集中 | 初期実証パートナー募集 |

## 2. トーン・デザイン要件

- 16:9 / **1920×1080**
- 白・ネイビー・グレー基調、アクセントはオレンジ（1スライドあたり1〜2箇所程度）
- BtoB向けの信頼感を保つ。**学生団体っぽく安く見せない**
- 文字少なめ・図解中心・**1スライド1メッセージ**
  - ただし料金プラン比較表など情報量が本質的に多いスライドは、表組み・グリッドで整理し、詰め込みすぎないレイアウトにする
- タイトル **48px以上**、本文 **28px以上**
- ページ番号を右下に `01 / 16` 形式で表示
- 図解は画像素材を使わず、**SVGまたはCSSで自作**する

| No | 内容 |
| --- | --- |

| 15 | 今後の進め方（STEP1〜5） |
| 16 | クロージング |

### 整合性ルール（矛盾を出さない）

- **P.08**：交流会がない月の共通提供内容は「企業紹介／少人数交流／学生イベント参加枠」までに限定する。
  学生リサーチ・個別マッチングは**プランB以上の特典**なので、共通提供内容として書かない。
  ※学生イベント参加枠はP.12でプランB特典に該当するため、P.08では「プランに応じて提供」の注記を必ず添える。
- **P.11 と P.14 の役割分担**
  - P.11 = 関係を通じて継続的に**お願いしたいこと全般**
  - P.14 = **募集の骨子**（対象・募集内容）のみ。手続き的な話はP.14、期待の詳細はP.11。
- **P.12 と P.13 の整合**
  - P.13 グループ1（全プラン共通）＝ 交流／簡易相談／企業紹介／合同交流会参加権 → プランAの内容と一致
  - P.13 グループ2（プランにより追加）＝ 学生リサーチ／採用・広報相談／個別マッチング／学生イベント参加枠の拡大／ミニプロジェクト応募権 → プランB以上（P.12 プランB の追加項目と1対1で対応させること）
  - グループ2はグループ1より視覚的に控えめにし、「全員が同じものを得られるわけではない」ことが一目でわかるようにする
- 料金が「候補」であることは **P.12だけでなく資料全体**（P.08注記・P.13・P.15など）で読み取れるようにする
