# BaseAI / SIB Company Deck v2 — Editorial Redesign

初版（`deck/index.html`）を、地域コミュニティの事業物語として再設計したバージョン。
25ページ → **20ページ**に再構成。テンプレート的な「タイトル＋3カード」を排し、内容の型ごとに
異なるレイアウト（エディトリアル・ステートメント／フィールドノート／バリューチェーン／
パスウェイ／インデックスリスト／ドキュメントモック／ラダー／カレンダー帯／レシート／
ブループリント／ケースファイル／展開ロードマップ）を割り当てている。

## 変更点と理由

| # | ページ | 変更 | 理由 |
|---|---|---|---|
| — | 全体構成 | 25→20ページに統合（p3/p4、p8/p9、p19/p20 を統合） | 同じ主張の重複を解消し、ページを増やす代わりに主張の解像度を上げるため |
| 全ページ | 見出し | トピック名→結論（Claim）に書き換え | 「1ページ1主張」を徹底するため |
| 全ページ | 装飾 | 丸角カード・グロー・光る接続線・角丸アイコンを撤去 | 「AIっぽいテンプレ資料」に見えるのを避けるため |
| 09 | 案件モック | 「（実在の相談ベース）」の記述を「（想定例）」に修正 | 検証できない実績を事実として断定していたため（捏造回避） |
| 18 | マッチング事例 | 「匿名化」表記を「想定」に修正、「特定の事例をもとにした」を削除 | 実在の個別事例であるかのような誤解を避けるため |
| 14 | イベント頻度 | カレンダーに架空の具体月（2/4/6/10月）をマークしていたのを削除し、頻度は「年6回」を示す抽象ドットに変更 | ブリーフに書かれていない具体的な月を捏造していたため |
| 全ページ | 改行 | 「湘南」「実行力」「企業課題」等の語が行またぎで分割されていた箇所に `<br>` / `nowrap` を追加 | 日本語の不自然な改行を解消するため |
| 07/13/10/14/17/19 | 余白 | コンテンツを縦方向に中央寄せ | 余白が「意図」ではなく「未使用」に見えていたため |

## QA

1. Chromium(Playwright) で全20ページをレンダリングし、DOM要素のオーバーフローを自動検査 → 0件
2. 接触シート（`contact_sheet.png`）で全ページを俯瞰し、以下を確認
   - 同一レイアウトが3ページ以上連続していない
   - 見出し位置・使用色（Coral）がページごとに単調になっていない
   - 枠・線・ドットに意味のない装飾がない
   - 1ページ内の視線の主役が1つに絞られている
3. 日本語の改行崩れ・文字切れを個別に目視確認し修正
4. `page.pdf()` で `BaseAI_SIB_CompanyDeck_v2.pdf` を出力（20ページ、1920×1080px = 1440×810pt）
