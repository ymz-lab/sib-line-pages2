## 01 / 表紙

**このスライドで伝えたいこと**
SIBが「学生団体」であると同時に、湘南を拠点とした実体のあるコミュニティであること。

**30秒説明**
「学生団体SIB、正式名称 Shonan Innovation Base です。湘南を拠点に、学生・企業・地域をつなぎ、
学生に挑戦のきっかけを届けている団体です。これまでに累計300名以上の学生が参加し、
15回のイベントを開催、10社以上の企業にご協力いただいてきました。」

**補足**
写真は実際のイベント（SIB × HERO'ZZ 共催イベント）の集合写真です。規模感と雰囲気が一目で伝わります。

**経営者に伝えるべきポイント**
最初の数秒で「学生のサークル」ではなく「実績のある組織」という印象を持ってもらうこと。
数字（300名+ / 15回 / 10社+）を先に見せるのが有効です。

## 02 / SIBとは何か

**このスライドで伝えたいこと**
SIBの存在意義は「イベントを開くこと」ではなく「学生と社会の最初の接点をつくること」。

**30秒説明**
「SIBは、学生と社会の間にある“最初の一歩”をつくる場です。
学生には挑戦の入口を、企業には若者との接点を、地域には新しい循環を。
イベントはあくまで手段で、そこで生まれた接点を、インターンや採用、共創企画といった
次の行動につなげることを大切にしています。」

**補足**
「出会って終わりにしない」というのがSIBの一貫した姿勢です。08枚目の実際の成果につながる伏線になります。

**経営者に伝えるべきポイント**
3つ並んだうちの真ん中「企業には、若者との接点を」が自社に関わる部分だと明示すること。
ここで「うちに何の関係が？」と思われないよう、早めに接続してください。

## 03 / なぜ今、SIBなのか

**このスライドで伝えたいこと**
学生・企業・地域それぞれに課題があり、その間をつなぐ役割が空いている。

**30秒説明**
「学生は社会人と話す機会が少なく、実践の場もない。企業は若者のリアルな価値観がつかみにくく、
採用や広報で若年層に届きにくい。地域は若い世代が出ていってしまい、担い手が不足しています。
三者とも困っているのに、日常のなかで交わる接点がない。
だからSIBは、三者をつなぐ“接点のインフラ”になることを目指しています。」

**補足**
ここは「SIBがなぜ必要か」の論拠パートです。真ん中の「企業側の課題」を、相手企業の実感に
合わせて一つだけ深掘りすると刺さります。

**経営者に伝えるべきポイント**
「採用・広報で若年層に届きにくい」は多くの経営者に共通する実感です。
ここで一度「御社ではいかがですか？」と問いかけると、以降の話が自分ごとになります。

## 04 / SIBが生み出す価値（循環図）

**このスライドで伝えたいこと**
SIBは一方向の支援ではなく、三者の価値が循環する構造をつくっている。

**30秒説明**
「SIBを真ん中に、学生・企業・地域が循環する構造をつくっています。
学生には挑戦の機会とキャリアの導線。企業には若者接点とインサイト、採用広報と共創の起点。
地域には、人と企業がつながり続ける新しい循環。この三方向がまわることが、SIBの価値です。」

**補足**
図の中心にSIBを置いているのは、SIBが「主役」ではなく「ハブ」だからです。

**経営者に伝えるべきポイント**
「学生を支援してください」という話ではなく「三者にメリットがある構造です」と伝えること。
善意やCSRではなく、事業的に合理性がある関わり方だという位置づけを崩さないでください。

## 05 / SIBが大切にしている4つの軸

**このスライドで伝えたいこと**
SIBの判断基準が言語化されていること＝運営が場当たりではないこと。

**30秒説明**
「SIBは、挑戦・接点・共創・実践という4つの軸を判断基準にしています。
初めての学生でも一歩踏み出せる設計にすること。普段生まれない出会いを意図的につくること。
出会いを企画や採用に発展させること。そして、机上ではなく実際にやってみること。
イベント企画から日々の運営まで、この4つで判断しています。」

**補足**
時間が短い場合は飛ばしても構いません（06枚目以降が本題）。

**経営者に伝えるべきポイント**
経営者は「理念があるか」「言語化されているか」を見ています。
学生団体が価値観を明文化している時点で、組織としての信頼材料になります。

## 06 / 学生コミュニティとしての特徴

**このスライドで伝えたいこと**
SIBに集まるのは受け身の学生ではなく「動きたい」層であること。そして今後の拡大目標。

**30秒説明**
「集まるのは、動きたいと思っている学生です。高校生から大学生まで、AI×SNSに興味がある層、
起業意欲がある層、インターンに挑戦したい層、就活真っ只中の層。
今年中に所属学生300名、リーチ可能な学生1,000名以上を目標に置いています。
運営はコア5〜10名の少数精鋭で、企画から集客・当日運営・広報まで学生自身が担当しています。」

**補足**
300名・1,000名+は**目標値**です。スライド上も「目標値」と明記しています。実績（07枚目）と
混同されないよう、言い方を分けてください。

**経営者に伝えるべきポイント**
「量」ではなく「質」の話をすること。動く意欲のある学生に絞って集めているからこそ、
企業が接点を持つ価値がある、という順序で説明してください。

## 08 / 代表的な活動実績

**このスライドで伝えたいこと**
集客・運営・外部連携を学生チームが主体で実行できること。そして成果が出ていること。

**30秒説明**
「代表的な2件です。第一回ピッチコンテストは2025年4月、新宿で開催。学生50名が当日結成の
チームで3分間のピッチに挑戦し、企業関係者6名、スポンサー10社にご協力いただきました。
9月にはHERO'ZZさんとの共催イベントを浜松町で開催。学生40名が著名ゲストと近い距離で対話し、

実際に人材の動きにつながった実例として、必ず言及してください。

## 10 / 活動を通じて生まれた価値

**経営者に伝えるべきポイント**

## 11 / 企業・経営者にとっての価値 ★重要

**このスライドで伝えたいこと**
SIBと関わることは支援ではなく、自社の採用・広報・事業への投資であること。

**30秒説明**
「企業・経営者にとっての価値を6つに整理しました。
若者との継続的な接点、アンケートでは出てこない学生のリアルな声、採用・広報・SNS発信への活用、
将来の人材との早期接点、湘南エリアの地域ネットワーク、そして共創企画の立ち上げ。
“学生を支援する”ではなく、“自社に若者の視点を取り込む”と捉えていただきたいと考えています。」

**補足**
この資料で最も重要なスライドです。ここだけは飛ばさず、相手の関心に近い項目を1〜2個選んで
具体化してください（例：採用課題があるなら 01・04、広報課題なら 02・03）。

**経営者に伝えるべきポイント**
6つ全部を平等に説明しないこと。相手の課題に当たる項目を1つ深掘りし、
「御社の場合はここが一番効きそうです」と言い切るほうが伝わります。

# 出力・運用メモ

## PowerPoint（.pptx）

`deck/sib-deck.pptx` … 18枚 / 16:9（13.333 × 7.5 inch）。
各スライドは3840×2160の画像として配置し、**このスピーカーノートを各スライドのノート欄に埋め込んで**います。
PowerPointの発表者ツールでそのまま表示されます。

- そのまま転送・共有できます（フォント環境に依存せず、どの端末でも同じ見た目になります）
- スライド上の文字を編集することはできません。**内容の修正は `index.html` / `style.css` を編集し、
  再度PPTXを書き出す**運用になります
- 書き出し手順：`index.html` の各 `.slide` を1920×1080（2倍解像度）で画像化し、
  13.333×7.5inchのスライドに全面配置します

## PDFで出力する

1. `deck/index.html` をブラウザ（Chrome / Edge 推奨）で開く
2. 右下の **「PDF出力」** ボタン、または `Ctrl/Cmd + P`
3. 用紙サイズ **1920×1080px（横）**、余白 **なし**、**背景のグラフィック** にチェック
4. 保存すると 18ページ（16:9）のPDFになります

コマンドラインから出力する場合（Playwright／Puppeteer）：

```js
await page.pdf({
  path: 'sib-deck.pdf',
  width: '1920px',
  height: '1080px',
  printBackground: true,
});
```

## 各スライドをPNGで書き出す

各スライドは `id="s01"` 〜 `id="s18"` を持ち、1920×1080の独立した要素です。

- **ブラウザだけで行う場合**：右下の「1枚表示」を押すと1スライドずつの表示になります。
  `index.html#s07` のようにURLへ直接アクセスすると、そのスライドを開いた状態で始まります。
- **自動で全枚数を書き出す場合**：`.slide` 要素を1つずつスクリーンショットします。

```js
const slides = await page.$$('.slide');
for (const s of slides) {
  const id = await s.getAttribute('id');
  await s.screenshot({ path: `${id}.png` });
}
```

## 画面表示について

- 画面幅に合わせて自動縮小されます（1920px幅より狭い環境でも全体が収まります）
- `←` `→` キー、または右下のボタンでスライドを移動できます
- 右下の操作ボタンはPDF・PNG出力時には含まれません

## 更新するときの注意

- 1スライドの安全領域は上下左右に余白を取った **1680 × 884px** です。
  これを超えると内容が見切れます（現在は全18枚が範囲内に収まっています）。
- 見出しは48px以上、本文は24px以上を維持してください（現在：スライドタイトル68〜148px、本文24〜32px）。
- 画像は `assets/images/` を参照しています。
  なお `second-pitch.jpg` と `workshop-wide.jpg` は拡張子が `.jpg` ですが中身がHEIC形式のため、
  ブラウザで表示できません。本資料では表示可能な別の写真を使用しています。
  差し替える場合は、事前にJPEG／PNGへ変換してください。
